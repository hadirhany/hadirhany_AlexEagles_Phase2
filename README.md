# To-Do List Web App (React + Flask)

## Run the backend
    cd backend
    python -m venv venv
    venv\Scripts\activate        venv/bin/activate
    pip install -r requirements.txt
    python app.py                # http://localhost:5000

## Run the frontend (new terminal)
    cd frontend
    npm install
    npm run dev                  # http://localhost:5173
